02Before / after

The three things that annoy you

Most screenshot tools capture pixels and call it done. These are the small failures that make you take the shot again.

01

The tray menu ends up in the shot

Clean Shot closes tray flyouts and popups before capturing, so they never end up in the screenshot.

02

Another app hijacked PrtSc

NeatShot listens to PrtSc, and Ctrl + Shift + A always works — even when something else grabs the key first.

03

The selection drifts on a 150% monitor

Per-Monitor DPI aware across mixed scaling — 100%, 125%, 150% — so what you select is exactly what you get.

03Annotate

Mark it up before you paste it.

Every tool you need to explain a screenshot, and two for hiding what shouldn't be in it.

  1. ArrowPoint at the exact button.
  2. RectangleFrame the field that matters.
  3. TextType a note right on the capture.
  4. Step badgesClick to drop 1, 2, 3… in order.
  5. PixelateHide tokens, keys and emails.
  6. BlurSoften faces and avatars.
Also: pencil, highlighter, ellipse, line, eyedropper, undo / redo.

06Text extraction

Get NeatShot for Windows

Requirements

  • Windows 10 (2004+) or Windows 11
  • x64
  • ~64 MB zip · no installer
  • No .NET runtime needed

Install in three steps

  1. 1Download the zip from GitHub Releases.
  2. 2Extract it anywhere and run NeatShot.
  3. 3It sits in the system tray. Press Ctrl + Shift + A.
About SmartScreen

This build isn't code-signed yet, so Windows may show a SmartScreen prompt the first time. Choose More info → Run anyway. The source is public if you'd like to read it first.
